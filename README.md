# 💰 Expense Tracker

## Overview

A console-based Expense Tracker developed using Python. It helps users manage income, expenses, transactions, monthly savings, and generate expense reports.

## Features

* Add Income
* Add Expense
* Add Transaction
* View Transactions
* Calculate Monthly Savings
* Show Expense Categories
* Save Data to CSV
* Expense Pie Chart
* Monthly Saving Graph

## Technologies Used

* Python
* CSV Module
* Matplotlib

## How to Run

1. Download the project.
2. Open the terminal.
3. Run:

```bash
python expense_tracker.py
```
